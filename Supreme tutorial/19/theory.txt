Свойство border-spacing задает отступ между ячейками td или ячейками th HTML таблицы
Значением свойства служат любые единицы для размеров, кроме процентов.
border-spacing: одно или два значения;
одно значение одинаковые отступы между ячейками по вертикали и по горизонтали.
два значения Первое значение задает отступ по горизонтали, а второе значение - отступ по вертикали.
работает только для ячеек таблиц с текстом в ячейках не работает
